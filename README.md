# Portafolio — Eulemis Hernández

Curriculum Vitae web (HTML/CSS) con descarga a PDF, preparado para GitHub Pages.

## Vista local

Abre `index.html` en el navegador, o sirve la carpeta:

```bash
npx serve .
# o
python3 -m http.server 8080
```

## Acciones

- **Download PDF** — genera `Eulemis-Hernandez-CV.pdf` (html2pdf.js)
- **Print** — diálogo de impresión del navegador (también útil como PDF)

## Archivos

| Archivo | Uso |
|---------|-----|
| `index.html` | Estructura del CV |
| `styles.css` | Estilos pantalla + print A4 |
| `script.js` | Descarga PDF |
| `assets/eulemis-hernandez.png` | Foto de perfil |

## GitHub Pages

Si el repo está en Pages, la URL típica es:

`https://eulemis.github.io/portafolio/`
