# Portafolio — Eulemis Hernández

Curriculum Vitae web (HTML/CSS) con descarga a PDF, publicado en GitHub Pages.

## Sitio en vivo

**https://eulemis.github.io/portafolio/**

## Vista local

```bash
cd portafolio
python3 -m http.server 8080
```

Abre `http://localhost:8080`

## Acciones

- **ES / EN** — cambia el idioma del CV
- **Descargar PDF** — CV visual (diseño con foto)
- **PDF ATS** — TXT + PDF una columna para portales de empleo
- **Imprimir** — diálogo del navegador

## Archivos

| Archivo | Uso |
|---------|-----|
| `index.html` | Estructura del CV |
| `styles.css` | Estilos pantalla + print |
| `script.js` | i18n + descarga PDF |
| `i18n.js` | Textos ES / EN |
| `assets/eulemis-hernandez.png` | Foto de perfil |
